# Підсумкова контрольна робота, варіант №1

## Посилання

Moodle (web): https://ido-m.kneu.edu.ua/moodle/ . Курс: https://ido-m.kneu.edu.ua/moodle/course/view.php?id=5623 . Усі завдання: https://ido-m.kneu.edu.ua/moodle/mod/assign/index.php?id=5623 .

- Здача (це завдання): https://ido-m.kneu.edu.ua/moodle/mod/assign/view.php?id=262012

Ти виконуєш лише це завдання. Файли здачі клади в `execution/` поруч із цим файлом. На Moodle роботу не відправляй. Якщо крок не вийшов двічі поспіль, зупинись і опиши перешкоду.

Курс: Технології та фреймворки реактивного програмування (INIS46106U). Варіант №1: у списку учасників курсу для групи ІН-401 перший за прізвищем — Абакумов Вадим.

Здача: `execution/control.md` українською. П’ять завдань, кожне з підзаголовком. Код контрольної не пиши окремим проєктом: у практичних завданнях посилайся на класи і стек із `../05-security/execution/` (сервер) та `../06-vue/execution/` (клієнт).

Предметна система варіанта: «Факультатив». Є перелік курсів, за кожним закріплений один викладач. Студент записується на один або кілька курсів, дані про реєстрацію зберігаються. Після закінчення навчання викладач виставляє оцінку, яка зберігається в архіві. Орієнтовно 400 тисяч користувачів, одночасно до 2 тисяч.

## Завдання 1. Сутність і види реактивного програмування

Напиши 500–700 слів. Дай визначення реактивного програмування. Назви види, які розрізняє курс: реактивні потоки на JVM (Reactor `Mono`/`Flux`, RxJava) і реактивні UI-фреймворки (Vue, React, Angular). Для кожного виду — один абзац, чим він відрізняється від виклику, який блокує потік. Опрись на матеріали курсу:

- презентація теми 1: https://ido-m.kneu.edu.ua/moodle/mod/resource/view.php?id=251256
- Reactor: https://projectreactor.io/docs/core/release/reference/
- RxJava: https://github.com/ReactiveX/RxJava/wiki/How-To-Use-RxJava

## Завдання 2. Spring WebFlux

Напиши 500–700 слів про те, як WebFlux реалізує реактивність: Netty, `Mono`/`Flux`, функціональні маршрути і анотаційні контролери, неблокувальний доступ до даних. Порівняй з блокувальним Spring MVC одним абзацом. Приклади бери з маршрутів `/hello`, `/clients` і CRUD `/teachers` власного застосунку. Документація: https://docs.spring.io/spring-framework/reference/web/webflux.html

## Завдання 3. Класи сутностей

У `control.md` наведи повні поля класів, уже прийняті в курсі:

- `Teacher`: id, firstName, lastName
- `Course`: id, title, teacherId
- `Student`: id, firstName, lastName
- `Enrollment`: id, studentId, courseId
- `GradeRecord`: id, enrollmentId, grade

Під кожним класом одне речення, яке поле що зберігає в предметній області, і який зв’язок він реалізує: викладач веде багато курсів, студент має багато реєстрацій, реєстрація має один запис оцінки в архіві. Додай таблицю «клас — таблиця — зовнішній ключ».

## Завдання 4. Серверні технології

Обґрунтуй стек сервера саме для 400 тисяч користувачів і 2 тисяч одночасних сесій. Технології зафіксовані, інші не пропонуй:

- Java 17+ і Spring Boot 3
- Spring WebFlux на Netty
- PostgreSQL і R2DBC
- Flyway
- Spring Security WebFlux

Кожній технології — абзац, навіщо вона цьому навантаженню. Окремо напиши, чому для 2 тисяч одночасних з’єднань обрано неблокувальний R2DBC, а не блокувальний JDBC на один потік на запит.

## Завдання 5. Клієнтські технології

Обґрунтуй клієнтський стек. Технології зафіксовані:

- Vue 3
- Vue Router 4
- Vuex
- Axios
- Bootstrap 5

Кожній технології — абзац. Поясни три сторінки клієнта (курси, студенти, архів) і чому сесія Spring Security передається через `withCredentials`. React і Angular згадай одним реченням як можливі заміни з тексту лабораторної 06 і напиши, що в цій роботі лишається Vue.

## Перевірка

`control.md` містить п’ять підзаголовків. У завданнях 3–5 фігурують лише класи і технології з цього файлу. Числа 400 тисяч і 2 тисячі є в завданнях 4 і 5.
