# Факультатив — зведений проєкт (лаби 1–7)

Один монорепозиторій замість окремих `execution/` у кожній папці лабораторної.

| Каталог   | Що всередині                                              |
| --------- | --------------------------------------------------------- |
| `server/` | Spring WebFlux + R2DBC + Flyway + Security (фінал лаб 05) |
| `client/` | Vue 3 клієнт (лаб 06)                                     |
| `docs/`   | Звіти й артефакти здачі по лабах `01`…`07`                |

База PostgreSQL: `elective`, користувач `postgres`, пароль `postgres`, порт `5432`.

## Запуск

```bash
# сервер, :8080
cd server && mvn spring-boot:run

# клієнт, :8081 (окремий термінал)
cd client && npm install && npm run serve
```

Вхід у клієнті: `1111` / `1111`.

Postman: `server/elective.postman_collection.json` або `docs/04-r2dbc/elective.postman_collection.json`.

Папки `01-середовище` … `07-контрольна` у корені курсу лишаються як було; `main/` — копія для роботи в одному місці. Після змін у лабах можна знову скопіювати в `main/` або правити напряму тут.
