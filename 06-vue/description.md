## Крок 1. Проєкт

У `execution/` створи проєкт Vue CLI з Vue 3. Підключи:

- `axios`
- `vue-router` 4
- `vuex` (у тексті завдання це названо vue-ex)
- `bootstrap` 5

Скрипт dev-сервера лишається стандартним Vue CLI. Порт клієнта `8081`, щоб не перетинатися з сервером на `8080`. Базовий URL axios: `http://localhost:8080`. Увімкни `withCredentials`, щоб сесія Spring Security ходила разом із запитами. На сервері дозволь origin `http://localhost:8081` з credentials.

## Крок 2. Сторінки

Зроби три маршрути і верхнє меню з `router-link` на кожен:

1. `/courses` — таблиця курсів: назва і викладач. Кнопка додає курс. Поля форми: назва курсу, вибір викладача зі списку `GET /teachers`. Збереження викликає `POST /courses`.
2. `/students` — таблиця студентів. Форма реєстрації на курс: вибір студента, вибір курсу, кнопка викликає `POST /enrollments`. Окремі поля додають студента через `POST /students`.
3. `/archive` — таблиця оцінок: студент, курс, оцінка. Форма виставляє оцінку через `POST /grades` для наявної реєстрації.

Меню видиме на всіх трьох сторінках. Назви пунктів: «Курси», «Студенти», «Архів».

## Крок 3. Вхід

На кожній сторінці, якщо запит до API повернув відмову в доступі, покажи форму логіна. Вона надсилає `POST /login` як form-urlencoded з полями `username` і `password`. Для перевірки використовуй `1111` / `1111`. Після успішного входу повтори запит сторінки.

Стан у Vuex: `username` поточної сесії і списки `teachers`, `courses`, `students`, `enrollments`, `grades`. Сторінки читають списки зі сховища, а сховище наповнює axios.
